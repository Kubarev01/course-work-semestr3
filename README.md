# ReleaseFlow

Курсовой проект Кубарева Егора, РИЗ-250938У: учёт задач и релизов разработки на Spring Boot.

## Запуск в Docker

Нужен запущенный Docker Desktop. Из корня проекта:

```sh
docker compose up -d --build
```

Открыть http://localhost:8082. Образ собирает исходники и выполняет тесты. Установка Java и Maven на компьютере не требуется.

```sh
docker compose logs -f app
docker compose down
```

База и журналы сохраняются в Docker volumes между перезапусками. Порт меняется в `docker-compose.yaml`.

## Локальный запуск

Нужна Java 17+. Maven Wrapper загрузит Maven при первом запуске:

```sh
./mvnw clean verify
sh run-demo.sh
```

Windows: `mvnw.cmd clean verify`, затем `run-demo.bat`.
Открыть http://localhost:8081.

## Учебные аккаунты

Профиль `demo` создаёт эти аккаунты и примеры задач только на пустой базе.
Общий учебный пароль: `ReleaseDemo!2026`.

| Логин | Роль |
|---|---|
| admin | ADMIN: все записи и управление ролями |
| egor | USER: свои задачи и релизы |
| anna | USER: отдельные задачи и релизы |
| viewer | READ_ONLY: просмотр общих записей |

Регистрация назначает READ_ONLY. Для создания своих записей администратор назначает USER. Учебные пароли предназначены для локальной демонстрации.

## Возможности

- Регистрация, вход и выход, BCrypt и CSRF.
- Создание, редактирование и удаление задач и релизов.
- Статусы, приоритеты, поиск, фильтры и доска задач.
- Трудоёмкость и дневная ставка; стоимость отдельной задачи = дни × ставка.
- Проверка владельца записи и защита от устаревшего сохранения через версию записи.
- Запрет удаления релиза с задачами.
- Журнал действий и назначение ролей администратором.
- Мониторинг Actuator доступен ADMIN.

Отдельный калькулятор общего бюджета и сроков удалён по запросу владельца.

## Структура

- `src/main/java` — контроллеры, сервисы, сущности, репозитории и настройки.
- `src/main/resources/templates` — HTML-шаблоны Thymeleaf.
- `src/main/resources/static` — CSS и JavaScript.
- `src/test` — интеграционные проверки.
- `pom.xml` — зависимости и сборка Maven.
- `Dockerfile`, `docker-compose.yaml` — сборка и запуск контейнера.

## Данные и проверки

`./mvnw verify` выполняет 39 проверок на изолированной H2 in-memory. Результаты появляются в `target/surefire-reports`.

Локальная база: `testdb/releaseflow.mv.db`, пользователь `sa`, пароль пустой. При подключении DBeaver Embedded остановить локальное приложение. Docker использует отдельную базу в своём volume.

Базы, логи, сборки и настройки редактора исключены из Git. Отчёт, скриншоты и материалы его подготовки хранятся отдельно от проекта.

# Требования курсовой
Источник: Курсовое проектирование SpringBoot (УрФУ, 2023).
Выбрана разрешённая авторская тема трекера разработки, вариант Task + Release.
Обязательны: регистрация READ_ONLY; вход; две таблицы с CRUD; пользователь USER видит только свои записи; ADMIN видит все; просмотр журнала user_actions; файловые логи; главная и О приложении; расчёт характеристик; управление ролями ADMIN; Actuator.
Пояснительная записка: определения, введение, обзор Java фреймворков, сравнение трёх БД, MVC, Lombok, JPA, схема БД и диаграмма классов, анализ вакансий, структура и реализация приложения, реальные UI-снимки, заключение, источники, Git и фрагменты кода, приложение с фактическим результатом антиплагиата.
Внешняя публикация не запрошена. Отчёт антиплагиата нельзя подменять выдуманным результатом.

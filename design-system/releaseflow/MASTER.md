# ReleaseFlow — рабочая область

Обновлено по запросу владельца: сдержанный зелёный интерфейс, компактные данные.

- Primary #286047; sidebar #203d30; background #f5f5ef; paper #fffef9.
- Ink #25332b; muted #627066; border #d9ded6.
- Системный шрифт, 14px основной текст, 28px заголовок страницы.
- Скругления 3–4px, без декоративных градиентов, крупных рекламных карточек и анимации.
- Сводка в единой полосе, таблицы с выделением строки, доска со статусными разделителями.
- Навигация: линейные SVG, активный раздел, видимый фокус клавиатуры.
- Зелёный — действие и завершение; охра — работа; красный — ошибка.
- Мобильная версия: перенос навигации, одноколоночные формы, горизонтальная прокрутка только внутри таблиц.
